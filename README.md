University Website
Description
A simple university website built with HTML, CSS, and JavaScript. The
webpage includes a header, navigation menu, content sections, a footer,
and a styled cards of different fields. It also includes an
interactive button that displays an alert message using a JavaScript
function.
How to Run the Project
1. Make sure the project files are saved in the same folder.
2. Open the project folder.
3. Find the main HTML file (usually named index.html).
4. Double-click index.html to open it in your web browser.
No additional software or installation is required. You can also open
the folder in Visual Studio Code and use the Live Server extension to
preview the website.
Technologies Used
- HTML
- CSS
- JavaScript
